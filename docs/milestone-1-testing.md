## What Was Delivered

The community platform has been installed, configured, and deployed to a live server with a secure cloud database. The platform structure has been tailored to the needs of the CoP — replacing the generic defaults with a foundation purpose-built for public policy evaluation professionals in Côte d'Ivoire.

### Platform & Infrastructure

- Live platform deployed and accessible at the URL above
- Cloud database provisioned and connected (PostgreSQL)
- Administrative access configured and secured
- Platform default language set to **French**

### Community Structure

Four discussion spaces have been created to organise community exchanges:

| Space | Purpose |
|-------|---------|
| **Annonces** | Official announcements and community updates |
| **Discussions Générales** | Open exchanges between community members |
| **Méthodologie & Outils** | Methods, tools, and best practices in evaluation |
| **Événements** | Training sessions, webinars, and upcoming events |

These categories can be expanded or refined as the community grows.

### Access Levels

Four levels of access have been configured to manage the community:

| Role | What They Can Do |
|------|-----------------|
| **Visiteur** (Guest) | Browse and read all public discussions |
| **Membre inscrit** (Registered Member) | Post topics, reply, upload files, vote |
| **Modérateur** | Edit, move, pin, or remove content; manage discussions |
| **Administrateur** | Full platform control — settings, users, structure |
